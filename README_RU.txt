РАСПИСАНИЕ БАШГАУ — ДЛЯ GITHUB PAGES

1. Распакуйте архив и загрузите все файлы с заменой в папку, которую публикует GitHub Pages.
   Главная страница должна называться index.html. Сам ZIP загружать вместо файлов не нужно.
2. Загрузите sw.js и manifest.webmanifest вместе с index.html: они нужны для офлайн-режима опубликованного сайта.
3. Откройте сайт с интернетом и дождитесь отметки «Офлайн готов». После этого проверьте открытие без сети.
4. В комплекте — присланный логотип БашГАУ: icon.png (512×512) и icon-192.png (192×192).
   Обе иконки должны находиться рядом с index.html. Имена файлов менять не нужно.
5. Меню → Офлайн-режим: инструкции для Android и iPhone, а также скачивание отдельного HTML.

НОВЫЙ ДИЗАЙН
Боковая навигация на ПК, временная лента пар, карточка текущего занятия, обзор недельной нагрузки.
На телефоне — компактный таймер, календарь с количеством пар и нижняя навигация.
Новым посетителям по умолчанию открывается тема «Графит». Ранее выбранная тема сохранится.
Чтобы включить новую тему вручную: Меню → Цветовая тема → Графит.
Все прежние темы, языки, группы, фильтры недель и подгрупп сохранены.

Расписание встроено в HTML. Сохранённый index.html можно открыть отдельно без интернета;
для офлайн-работы опубликованного сайта загружайте весь комплект.
Если браузер показывает старую версию после обновления GitHub Pages, обновите страницу с очисткой кэша (Ctrl+F5).
